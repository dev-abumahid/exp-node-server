## Conventions

- Keep one model per domain area; the `generate` command adds new model files.
- Use transactions for multi-step critical writes.
- Add indexes for foreign keys, filters and sort fields.
- Never edit generated database clients or migration history by hand.
- Update this file with `npx exp-node-server ai sync --apply` after schema changes.

### Prisma

- Models live in `prisma/schema/*.prisma`; run `npm run db:migrate` after edits.
- Never change an existing model without a migration plan.

### Mongoose

- Schemas live in module `*.schema.ts` files; models are exported from there.
- Add indexes in the schema definition, not in service code.
- Never bypass the model layer with raw queries unless performance requires it.
