## What this project is

A modular Express API generated by exp-node-server. It includes authentication,
profiles, rate limiting, background email jobs and Swagger documentation.

## Commands

- `npm run dev` - start with tsx watch
- `npm run check` - TypeScript typecheck
- `npm run lint` / `npm run lint:fix`
- `npm test` - Vitest
- `npm run build` - compile to dist
- Prisma projects only: `npm run db:migrate`, `npm run db:deploy`

## Runtime shape

- `src/app.ts` builds the Express app (security, CORS, docs, routes, errors).
- `src/server.ts` connects the database, starts queues and shuts down gracefully.
- `src/routes.ts` mounts module routers under `/api`.
- `src/app/modules/<module>/` contains route -> controller -> service -> database code.
- `src/app/configs/index.ts` validates environment variables with Zod.
